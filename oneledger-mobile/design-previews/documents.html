Try the flow

  1. Open Statements → Create statement.
  2. Choose accounts, period and detail level.
  3. Review the selection. Live generation will show authoritative totals and coverage before submission.
  4. Open an existing statement for details and PDF/CSV actions.
  5. Use Schedule to see the proposed daily report settings.

What the code review found

The web already has a generator with account authorization, role capabilities, server-side totals, coverage warnings, immutable snapshots, queued large jobs and duplicate-request protection. The native app currently exposes only list/download endpoints.

Implementation boundary

Add authenticated mobile options/preview/generate endpoints around the existing generator. Preserve Space checks, second-factor requirements and idempotency. Add schedule endpoints around the saved daily report preferences. Avoid recalculating statement totals in the phone UI.

Web report pages remained on loading placeholders during this review. That needs diagnosis separately from visual changes. This prototype intentionally does not simulate successful generation or delivery.

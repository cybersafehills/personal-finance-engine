# OneLedger logo assets

See `docs/ONELEDGER_BRAND_ASSETS.md` at the repo root for full usage rules.
Quick reference for this folder:

- `oneledger-logo-primary.png` - full-color horizontal lockup, light backgrounds.
- `oneledger-logo-monochrome-dark.png` - single-tone dark lockup, for print or
  monochrome-only contexts. Reconstructed from a source export that had lost
  its transparency (baked-in checkerboard); geometry/colors are untouched -
  only true alpha was restored. See the brand doc's "Source-of-truth
  warning" section before touching this file again.

Do not resize these below legibility, recolor them, or use them inside
small square containers - use `../mark/oneledger-mark.png` there instead.
